DSA Practice Problems - Multiples of Three
Problem 1: Find All Multiples of 3
You are given an array A of N integers. Return all numbers from the array that are divisible by 3. If
no such number exists, print -1.
Input Format:
First line: Integer N
Second line: N space-separated integers
Output Format:
Print all multiples of 3 in the same order as input.
If none exist, print -1.
Constraints:
1 ≤ N ≤ 10^5-10^9 ≤ A[i] ≤ 10^9
Example:
Input:
7
2 3 6 7 9 10 12
Output:
3 6 9 12
Problem 2: Longest Consecutive Multiples of 3
You are given an array A of N integers. Find the length of the longest consecutive sequence
(continuous in array) where all elements are divisible by 3.
Input Format:
First line: Integer N
Second line: N space-separated integers
Output Format:
Print the length of the longest consecutive block of multiples of 3.
Example:
Input:
10
3 6 9 2 12 15 18 5 21 24
Output:
3
